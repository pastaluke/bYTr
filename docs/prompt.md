# bYTr — Project Description

## What It Is

bYTr gives users better YouTube recommendations than the official YouTube algorithm.

It helps users identify what they genuinely enjoy about their favorite content creators — not surface-level categories, but deeper human qualities — and then finds other creators and content that share those qualities.

## The Core Difference

Mainstream recommendation algorithms optimize for **capitalistic outcomes**: watch time, ad revenue, engagement metrics.

bYTr is an experiment in building algorithms that optimize for **human-centered, meaningful outcomes** instead.

## How It Works

1. User identifies their favorite creators
2. App helps them surface what they actually value about those creators (see: Values)
3. Algorithms find other creators/content matching those values
4. Emphasis is on **filtering out** shallow similarities (genre, category, format) and **filtering in** deeper ones

## Values (Examples)

- Determined
- Sincere
- Inclusive
- Dedicated to craft
- _(more to be defined)_

## Purpose

This project exists to **discover and refine algorithms** that surface human-centered content — and to demonstrate that recommendation systems don't have to serve capital at the expense of users.
